# data/public/

The released dataset. Everything here is generated by
`scripts/prepare_release.py` and should not be edited by hand.

| File | Contents |
|---|---|
| `postings_public.csv` | One row per advertisement: identifiers, source URL, capture date, title, location, coded signals, SHA-256 of the text |
| `counts_country_by_platform.csv` | Country by platform, each posting counted once |
| `counts_hub_by_platform.csv` | Hub by platform, matching the article's Figure 2 |
| `release_manifest.json` | Row counts, per-file checksums, settings, and whether the integrity checks passed |

Check `release_manifest.json` first. If `checks_passed` is false, the release
was forced and the failures are listed in the same file.
